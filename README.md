# 远程设备固件分批发布控制台

源提示词摘要：发布负责人选择设备范围、固件版本、分批比例和回滚版本，运维设定兼容条件与失败阈值，值班人员监视下载、安装、重启和异常事件；关键发布支持审批、暂停、继续和紧急回滚，过期状态不可误用。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 可用流程

- 创建发布批次并关联设备分组、固件版本、分批比例和失败阈值。
- 批次从草稿、已审批、排队中、发布中、暂停到完成或回滚。
- 兼容条件阻止不合格分组加入发布；实时指标由本地遥测模拟驱动。
- 审批、暂停、继续、回滚和状态变化保留审计记录并持久化到 localStorage。

## 区域与权限

- 发布负责人可处理全部区域，跨区紧急回滚仅发布负责人可执行。
- 区域运维只能处理本区网关的批次（审批、暂停、继续、回滚）。
- 值班人员仅可暂停异常批次，无审批、恢复和回滚权。
- 越权操作会被拒绝并写入审计记录。

## 区域容量与排队

- 每个区域有每轮下发容量上限，超出容量的设备先排队。
- 紧急回滚立刻插队（回滚批次优先级最高），同区其他批次未下发设备全部重排。

## 弱网回执补报

- 设备回执按批次 + 设备 + 类型去重，重复只算一次。
- 补报失败的回执按设备重试；已停批次（暂停/回滚）的回执退回待核对。

## 并发提交冲突

- 批次带版本号，两人同时提交同一批设备时先到的一版生效。
- 后到者提交会看到冲突设备清单，可在冲突面板核对。

## 型号清单变更

- 型号清单变更后，未下发名额立即重算（待下发 = 计划 - 已安装 - 已下发）。
- 已安装和已下发的设备保留结果，不受清单变更影响。
