# 远程设备固件分批发布控制台

按区域隔离管理远程固件发布：区域运维只能处理本区网关批次，跨区紧急回滚由发布负责人执行；每区域下发容量有上限，超额设备排队，紧急回滚立即插队并让其他批次重排；弱网回执按设备补报、重复只算一次，已停批次的回执退回待核对；并发提交同一批设备先到先得；型号清单变更后未下发名额立即重算，已装上的结果保留。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 已实现规则

- **区域权限隔离**：角色可在右上角切换（发布负责人 / 区域运维 + 所属区域）。区域运维的创建、审批、暂停、继续、回滚均限制在本区；跨区紧急回滚仅发布负责人可执行，拦截会记录审计。
- **区域容量与排队**：每个区域有在途下发上限（华东 6 / 华南 5 / 新加坡 4）。超出容量的设备按 FIFO 排队，容量释放自动补位，队列面板实时展示。
- **紧急回滚插队**：回滚槽位优先级 0，永远排在普通发布前；容量占满时立即抢占其他批次的在途名额，被抢占设备退回队列重排，全过程写审计。
- **弱网补报回执**：标记"弱网"的设备完成后回执进入按设备重试队列（记录尝试次数）；同设备同批次同结果的重复回执只算一次；批次已暂停/已回滚时到达的回执进入"待核对"，由值班人员确认入账或驳回重试。
- **并发提交冲突**：设备占用（claim）先到先得。「模拟两人同时提交」在同一事件循环内连续派发两次提交，先到一版全部生效，后到一版只在冲突面板看到冲突设备。
- **型号清单与名额**：名额 = 区域内符合型号且未产生过本批次结果的设备数 × 灰度比例。型号清单可在批次卡片上直接修改：未下发（排队/claimed）的设备立即释放、名额实时重算；成功装上的结果保留；已有结果（含失败）的设备不再重占名额。
- 失败率超过阈值自动暂停；状态持久化到 localStorage（结构版本不匹配时丢弃旧状态，避免过期状态误用）。
