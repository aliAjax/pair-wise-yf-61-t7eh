# 规则端到端仿真（Node 环境）

纯函数驱动 `releaseReducer`，不依赖浏览器与 Angular 运行时：

```bash
node .simtest/build.mjs   # 用 esbuild 打包（@ngrx/store 用纯函数桩替换）
node .simtest/run.mjs     # 运行 6 组规则共 26 项断言
```

覆盖：

1. 区域 RBAC：区域运维仅限本区，跨区紧急回滚仅发布负责人
2. 区域容量：在途不超容量，超额排队，释放后 FIFO 补位
3. 紧急回滚：priority=0 立即插队，其他批次在途设备让位重排
4. 弱网补报：按设备重试、重复只算一次、停批次回执退回待核对
5. 并发提交：先到先得，后到者只收到冲突设备面板
6. 型号清单变更：未下发名额立即重算，已装上结果保留
